oaknut
======

Python tools for Acorn computer filesystems, files, and formats — the
BBC Micro, Electron, Archimedes, and their descendants.

Most readers reach for the ``disc`` :doc:`command-line interface
<cli/index>` to inspect, extract, or modify Acorn disc images from a
shell. The :doc:`Python API <api/index>` is for programs that consume
the on-disc formats directly.

If you have not yet installed anything, start with the :doc:`install`
guide.
