Python API
==========

Use the Python API when you need to compose Acorn-filesystem operations
inside a larger Python program — building a disc image as part of an
asset pipeline, scripting WFSINIT setup across many discs, integrating
with an emulator, or implementing a feature the CLI does not yet expose.

For ad-hoc operations from a shell, the :doc:`/cli/index` is usually
the friendlier tool.
