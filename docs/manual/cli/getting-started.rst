Getting started
===============

A 10-minute walkthrough that takes a reader from an unfamiliar shell
prompt to listing, extracting, and modifying an Acorn disc image.

.. note::

   This page is a placeholder. Final content will cover:

   - opening a real image (DFS floppy, ADFS hard disc, AFS server disc)
   - listing the catalogue with ``disc ls``
   - extracting a file with ``disc get`` / ``disc cat``
   - inserting a file with ``disc put``
   - making a fresh image with ``disc create``
   - what to read next (the :doc:`cookbook` and :doc:`conventions/index`)
