oaknut

Python tools for Acorn computer filesystems, files, and formats — the BBC Micro, Electron, Archimedes, and their descendants.

  • disc
    Inspect, extract from, and modify Acorn disc images — DFS, ADFS, AFS — from the disc command line or the Python API.
  • zip
    Read ZIP archives that carry Acorn file metadata: load and execution addresses, access bits, and RISC OS filetypes.
