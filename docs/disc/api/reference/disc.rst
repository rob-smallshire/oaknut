``oaknut.disc``
===============

The unified ``disc`` command-line tool. Its commands are documented
under :doc:`the CLI reference </cli/commands/index>`; this page covers
the small Python API it also exposes for driving the same operations
from a script — no shell required.

Every name documented here is importable directly from ``oaknut.disc``.
